CivilSpellAI 1.2.13.0

Complemento piloto para Autodesk Civil 3D 2024 de 64 bits.

Comandos

  • AISPELL: revisa un DBText, MText, MLeader textual o atributo seleccionable.
  • AISPELLALL: revisa DBText, MText, MLeader textual, celdas simples de Table y textos o atributos de bloques locales.
  • AISPELLSETTINGS: administra proveedores, privacidad, diagnóstico y glosario.

Ninguna propuesta se escribe sin aprobación. Cancelar, cerrar o encontrar un conflicto conserva el texto original.

La versión 1.1 incorpora edición manual validada, progreso y filtros de lote, elección por fila y memoria local explícita y revocable.

El mantenimiento 1.1.1 mejora la navegación por teclado, la compatibilidad con alto contraste y lectores de pantalla, y contiene fallos locales de permisos o exportación sin propagarlos a Civil 3D.

La versión 1.1.4 sincroniza la fila seleccionada con el foco de teclado y anuncia con mayor claridad estados y motivos de bloqueo.

La versión 1.1.5 aclara que una sola orden U revierte todo el lote de AISPELLALL y añade una regresión automatizada en AutoCAD.

La versión 1.2 amplía la revisión global a MLeader, celdas editables de Table y textos o atributos de bloques locales. Omite referencias externas, fórmulas, campos, vínculos de datos y etiquetas nativas de Civil 3D.

La revisión local incorpora los diccionarios abiertos Hunspell es_PE para Perú y en_US para inglés estadounidense, y funciona sin conexión. Propone erratas cercanas únicamente cuando existe una sola alternativa segura. Los códigos y casos ambiguos no se cambian.

Los diccionarios y el motor administrado se distribuyen con sus respectivos avisos y licencias. CivilSpellAI no redistribuye contenido del DLE ni del DPD de RAE/ASALE.

LanguageTool local puede habilitarse en Ajustes para ampliar la revisión gramatical sin consumir API. Requiere un servidor iniciado en http://127.0.0.1:8081; Java y LanguageTool no forman parte del complemento. La conexión rechaza servidores remotos, proxy, cookies y redirecciones.

El botón Probar servicio local comprueba LanguageTool con una frase fija; no usa texto del dibujo ni guarda la respuesta.

La prueba de conexión de OpenAI en Ajustes envía únicamente una frase fija después de advertir el posible coste; no utiliza contenido del dibujo ni guarda la respuesta.

La configuración se guarda bajo %LOCALAPPDATA%\CivilSpellAI. En la primera ejecución de AISPELLALL, cada usuario puede abrir Ajustes o continuar localmente. La clave de OpenAI es opcional: puede guardarse desde un campo enmascarado como variable de entorno del usuario OPENAI_API_KEY, pero nunca forma parte del paquete ni del archivo de configuración. Cada computadora debe usar una clave autorizada para su usuario o proyecto y la conexión solo se prueba por acción explícita.
