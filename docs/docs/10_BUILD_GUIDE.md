# Build Guide

## Requisitos
- Visual Studio 2022
- .NET Framework
- Civil 3D 2024

## Referencias
- acmgd.dll
- acdbmgd.dll
- accoremgd.dll
- AeccDbMgd.dll

## Configuración
- Plataforma: x64
- Copy Local = False

## Compilación
Compilar -> Recompilar solución

## Salida
bin/x64/Debug/CivilSpellAI.dll

## Carga
NETLOAD
Seleccionar CivilSpellAI.dll
Ejecutar AISPELL
