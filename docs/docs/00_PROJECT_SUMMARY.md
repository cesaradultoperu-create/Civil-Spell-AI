# Project Summary

## Nombre
CivilSpellAI

## Resumen
Plugin para Autodesk Civil 3D orientado a la corrección ortográfica y lingüística de textos técnicos.

## Estado actual
- Proyecto .NET Framework
- Comando AISPELL
- Selección de texto
- SpellEngine desacoplado
- Reemplazo automático del texto en el dibujo
